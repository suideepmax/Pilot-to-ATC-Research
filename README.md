# Pilot-to-ATC Speech Recognition Research

Fine-tuning Wav2Vec2 for Air Traffic Control (ATC) communications.

Based on: [idiap/w2v2-air-traffic](https://github.com/idiap/w2v2-air-traffic)

## Environment Setup
- Python 3.10 (CPython via conda-forge)
- CUDA 11.7
- See `docs/SETUP.md` for full setup instructions

## Pipeline
1. Data preparation (UWB-ATCC corpus)
2. Fine-tuning Wav2Vec2
3. Evaluation with/without LM
